## Projects

**[CyberLens](https://github.com/ChaitanyaKash/CyberLens)**: sorts cybercrime complaints into 39 fraud subtypes and flags scam messages.
- Fused XLM-RoBERTa with TF-IDF, raising macro-F1 from 0.2345 to 0.2745 on the I4C CyberGuard data.
- Tested the scam detector on 5.7K real SMS (~0.76 macro-F1 vs ~0.97 on synthetic data), and now working on closing that gap.
- Added a RAG layer over official RBI, I4C and DoT documents: hybrid BM25 + embedding search, filtered by fraud type and incident date, that gives cited next steps and a complaint draft.
